# 审片工作台 · 演示

家装短视频投放前审核工具的界面演示。**纯前端，数据是假的**，用来看流程和交互。

在线看：https://daiuuuuu.github.io/yunwei-review-demo/

## 能看什么

- 登录 → 工作台 → 选片子 → 逐条改 → 导出
- 三档改法：必须改（卡审核）/ 建议改（大问题）/ 可以改（小问题）
- 每条带画面占位图，点图能圈出问题位置（方框、箭头、画笔、文字）
- 保存（草稿）与保存并标记已审核两种状态

## 演示环境的限制

- 没有真实视频和真实画面，用占位图代替
- 导出 Word 不可用（正式版会生成）
- 分析结果是预置的，不跑真引擎

## 正式版

Node 零依赖后端 + 判据引擎，跑在内网。判据改配置文件，不动代码。
